# Массовое списание старых долгов (Forma / 1С)

## Рекомендуется: внешняя обработка `.epf`

Папка сборки: [fitgo-writeoff-debts/README.md](./fitgo-writeoff-debts/README.md)

1. Один раз собрать в конфигураторе по инструкции (5–10 мин).
2. Сохранить `FitGO_СписаниеСтарыхДолгов.epf`.
3. В 1С:Предприятие → **Файл → Открыть** → выбрать `.epf` (фильтр «Внешние обработки»).
4. На форме: год / период → **Просмотр** → **Списать**.

Так не нужен `.bsl` и консоль кода.

## Альтернатива: консоль кода

[FitGO_СписаниеСтарыхДолгов_Консоль.bsl](./FitGO_СписаниеСтарыхДолгов_Консоль.bsl) — только если есть обработка «Консоль кода». Файл `.bsl` в 1С через «Открыть» не запускается (это текст).

## Суть

- Эталон списка: **Отчет.НеоплаченныеПродажи**
- Закрытие: **Документ.СписаниеЗадолженности**
- Тренировка: сначала **2019**, потом другие годы или 2018–2025
- Продажи не удаляются
