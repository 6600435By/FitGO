# Форма FitGO_DataScanner

Реквизиты созданы на **объекте** обработки (ветка «Реквизиты» у FitGO_DataScanner) — так и должно быть:

| Имя | Тип | Длина |
|-----|-----|-------|
| Телефон | Строка | 32 |
| ВнешнийИд | Строка | 36 |
| ПутьОтчёта | Строка | 260 |
| Статус | Строка | 0 |

В модуле формы обращение: **`Объект.Телефон`**, `Объект.ВнешнийИд`, …

## Форма

- Одна форма `Форма`, она же «Форма обработки»
- На форму перетащить 4 реквизита объекта
- Команда формы `Сканировать` → действие «Создать на клиенте» → вставить `FormModule.bsl`
- Событие формы «При создании на сервере» → `ПриСозданииНаСервере`
