# Форма FitGO_СписаниеСтарыхДолгов

Реквизиты создаются на **объекте** обработки (ветка «Реквизиты»), не на форме:

| Имя | Тип | Длина / точность | По умолчанию |
|-----|-----|------------------|--------------|
| ГодСписания | Число | 4, 0 | 2019 |
| ДатаНачала | Дата | — | из года |
| ДатаОкончания | Дата | — | из года |
| ЛимитСтрок | Число | 10, 0 | 0 (= все; для шага 3 = лимит **договоров**) |
| Лог | Строка | **0 = неограниченная** | — |
| СчетКлуба | СправочникСсылка.БанковскиеСчета | — | р/с клуба для безнала (напр. «Корпо») |
| ДатаОплатыИзДоговора | Булево | — | **Истина**: дата Поступления = дата начала договора; Ложь = конец периода продаж |

Если справочник счетов в вашей базе называется иначе (`БанковскиеСчетаОрганизаций` и т.п.) —
тип реквизита выберите по фактическому типу поля «Счет» в документе
«Оплата от страховой компании безналичными средствами».

**Обязательно:** у реквизита `Лог` длина должна быть **0**.  
Если стоит 10/50/100 — в поле останется обрубок вроде `Период: 01` (текст обрезается при записи).

Как проверить/исправить: дерево обработки → Реквизиты → `Лог` → свойства → **Длина = 0** → сохранить `.epf`.

На форму перетащить все реквизиты. Поле **Лог** — многострочное (высота ~12 строк).
