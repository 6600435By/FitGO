# FitGO — списание старых долгов (внешняя обработка `.epf`)

Готовый `.epf` с Mac собрать нельзя (нужен конфигуратор 1С).  
Сборка **один раз** на Windows RDP (~5–10 мин) — дальше в Предприятии: **Файл → Открыть → `.epf`**.

Исходники:

| Файл | Куда в конфигураторе |
|------|----------------------|
| [`ObjectModule.bsl`](ObjectModule.bsl) | Модуль объекта |
| [`FormModule.bsl`](FormModule.bsl) | Модуль формы |
| [`FORM.md`](FORM.md) | Реквизиты и кнопки |

Зеркало: `C:\fitgo-probe\1c-extension\fitgo-writeoff-debts\`

---

## Сборка `.epf` (один раз / после обновления BSL)

1. **Конфигуратор** → **Файл → Новый → Внешняя обработка** (или открыть уже собранный `.epf`)
2. Имя: `FitGO_СписаниеСтарыхДолгов`
3. Ветка **Реквизиты** — все из [FORM.md](FORM.md), включая новый **СчетКлуба**
4. **Модуль объекта** → Ctrl+A → вставить весь [`ObjectModule.bsl`](ObjectModule.bsl) → Ctrl+S
5. **Формы** → Добавить → `Форма` (основная / форма обработки) — если ещё нет
6. На форму перетащить реквизиты; поле **Лог** — многострочное
7. Команды формы — все из [FORM.md](FORM.md) → кнопки на форму (добавить кнопки шага 3)
8. Событие формы «При создании на сервере» → `ПриСозданииНаСервере`
9. **Модуль формы** → вставить [`FormModule.bsl`](FormModule.bsl)
10. **Файл → Сохранить как** → `C:\fitgo-probe\FitGO_СписаниеСтарыхДолгов.epf`

Если `.epf` уже был — достаточно обновить модули + добавить реквизит/кнопки шага 3.

## Запуск (каждый раз)

1. 1С:Предприятие → **Файл → Открыть** → фильтр **Внешние обработки (*.epf)**  
   → `FitGO_СписаниеСтарыхДолгов.epf`
2. **ГодСписания** = `2019` → кнопка **«Год → даты»**
3. **Шаг 1 — пометка.** «Просмотр пометки» → ЛимитСтрок `5` → «Пометить» → проверить карточки
   (долг и «Использовать» пропали, взаиморасчёты сходятся) → ЛимитСтрок `0` → «Пометить».
   - Помечаются только продажи **без единой оплаты**.
   - `SKIP` в логе = 1С не дала снять проведение (услуга использована) — это нормально.
4. **Шаг 2 — списание.** «Просмотр списания» → ЛимитСтрок `5` → «Списать» → проверить → `0` → «Списать».
   Прощает долг по оставшимся продажам (использованные / частично оплаченные); продажа и занятия остаются.
5. **Шаг 3 — корпо.** Заполнить **СчетКлуба** (р/с как на форме оплаты, напр. «…в Корпо»).
   Галка **ДатаОплатыИзДоговора** (по умолчанию вкл.) — зачисление на **дату начала договора**,
   не на сегодня / не на конец периода. Снять галку → дата документа = конец периода продаж.
   «3. Просмотр корпо» (в логе будет `дата док.=…`) → лимит `1`–`2` → «3. Оплатить корпо»
   → сверить → лимит `0` → все договоры периода.
6. Следующий год: `2020`, … или даты вручную (Год = 0).

Откат шага 1 — «Откатить пометки»; шага 2 — «Отменить FitGO» (в день списания);
шага 3 — «Отменить корпо FitGO» (по метке периода **продаж** в комментарии, даже если
дата документа = дата договора).
**«Удаление помеченных» не запускать.**

После очистки лет: опубликовать Analytics (знак долга) → в FitGO «Обновить из 1С».

## Корпоративные договоры (шаг 3)

Продажи с полем **Договор** = `Справочник.КорпоративныеДоговоры` (пример:  
`e1c://server/…/Справочник.КорпоративныеДоговоры?ref=…`) —
долг **организации**, не физлица. Шаги 1–2 их **исключают**.

Шаг 3 создаёт тот же документ, что вручную:

**Финансы → Поступления ДС → Безналичные →**  
«Оплата по корпоративному/страховому/кредитному договору»  
(заголовок формы: «Оплата от страховой компании безналичными средствами»).

На каждый договор (+ структурная единица) — один документ:

- операция / статья ДДС / контрагент-организация / договор — из метаданных и справочника;
- табличная часть — неоплаченные продажи периода (как «Заполнить» продажами);
- `Сумма` = сумма строк;
- дата документа = **дата начала договора** (если галка `ДатаОплатыИзДоговора`), иначе конец периода продаж;
- комментарий `FitGO: оплата корпо ДД.MM.yyyy..ДД.MM.yyyy` (период **продаж**, для отката).

### Важно

Документ попадает в **безнал и выручку**. Запускайте только когда:

- деньги по договорам уже были на р/с, а документов в 1С не хватает; **или**
- бухгалтерия явно согласовала закрытие старых корпо-хвостов этим способом.

Иначе сначала штатный путь Forma: акт → «Создать на основании → Поступление ДС»  
([оплата корп. договора](https://www.fitness1c.ru/knowledge-base/klienty/korporativnye-klienty/oplata-korporativnogo-dogovora-bez-ogranicheniy/)).

Отчёт сверки: **Клиенты → Отчеты по клиентам → Взаиморасчёты с корпоративными организациями**.

Если «Оплатить корпо» падает на метаданных — кнопка **«Проба метаданных корпо»**, лог пришлите в чат.

## Тренировка 2019

| Шаг | Действие |
|-----|----------|
| 1 | Бэкап ИБ |
| 2 | Год 2019 → Просмотр |
| 3 | Лимит 5 → Списать |
| 4 | Лимит 0 → Списать весь 2019 |
| 5 | СчетКлуба → Просмотр корпо → лимит 1 → Оплатить корпо → проверить |
| 6 | Лимит 0 → Оплатить корпо за год |
| 7 | Отчёт «Неоплаченные продажи» / взаиморасчёты корпо — пусто/минимально |

Консольный `.bsl` больше не нужен, если есть `.epf`. Старый скрипт: [../FitGO_СписаниеСтарыхДолгов_Консоль.bsl](../FitGO_СписаниеСтарыхДолгов_Консоль.bsl).
