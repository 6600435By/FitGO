# FitGO — справочник по домену (reference)

## Источники и что у них брать

### TrainingPeaks
- План vs факт тренировки
- Структурированные блоки (разминка / основная / заминка)
- TSS, длительность, комментарии тренера к сессии
- **Для FitGO:** итог занятия, блоковые заметки, история между сессиями

### Garmin
- Таймеры работа/отдых, круги, автолапы
- Зоны пульса, темп, дистанция, наклон (бег)
- Мощность/каденс (вело) → у нас **сопротивление / ватты**
- **Для FitGO:** `workout-timer.tsx`, поля pace/distance/incline/resistance

### Strava
- Дистанция, темп, сегменты
- Сравнение однотипных тренировок во времени
- **Для FitGO:** `circuit-dynamics`, динамика круговых, итоги по блокам

### Polar
- Z1–Z5, % HRmax
- Сочетание пульса и субъективных ощущений
- **Для FitGO:** поля `zone`, `hr`, `rpe`

### ACSM (FITT)
- Обязательные измеримые параметры любой аэробной нагрузки
- RPE как валидная субъективная метрика (шкала Борга 6–20 → в приложениях часто 1–10)

## Кардио — поля FitGO (текущий эталон)

| ID | Метка | Пример | Аналог |
|----|-------|--------|--------|
| modality | Тренажёр / вид | Дорожка | Garmin activity type |
| duration | Время | 20 мин | FITT — Time |
| distance | Дистанция | 3.5 км | Strava |
| pace | Темп / скорость | 6:30 / км | Garmin pace |
| hr | ЧСС | 145 | Polar |
| rpe | RPE | 7 | TrainingPeaks feel |
| zone | Зона | Z2, 70% | Polar zones |
| incline | Наклон | 5% | Garmin treadmill |
| resistance | Сопротивление | Ур. 8, 180 Вт | Garmin bike |
| intervals | Интервалы | 4×2 мин / 1 мин | Garmin intervals |
| notes | Заметка | Техника | TP comments |

**Миграция legacy:** `loadType→modality`, `interval→duration`, `lap→intervals`, `distanceIncline→distance+incline`.

---

## Силовая — поля

| Поле | Стандарт |
|------|----------|
| Упражнение | Название / паттерн движения |
| кг + повт | Раздельно (Strong, TP) |
| RPE | 1–10 на подход |
| restSec | Отдых между подходами |
| tempo | 3-1-2-0 гипертрофия / 2-0-2-0 выносливость |

---

## Круговая — минимальный набор станции

1. Название
2. workSec / restSec
3. load (кг / уровень)
4. targetHr
5. tempo (только силовые станции)

Журнал круга: avgHr, maxHr, RPE по станциям, фактический отдых.

## Биомеханика — поля FitGO

| ID | Метка | Пример | Аналог |
|----|-------|--------|--------|
| name | Название | «Кошка-верблюд» | TP exercise title |
| focusArea | Зона тела | Колено | FITT — Type (область) |
| exerciseType | Тип работы | Стабилизация | Garmin Mobility / Yoga |
| equipment | Инвентарь | Эспандер, блок | ACSM corrective tools |
| duration | Время | 30 сек | FITT — Time |
| volume | Объём | 3×10 | FITT — Volume |
| rpe | RPE | 4 | TrainingPeaks feel |
| side | Сторона | Левая | — |
| comfort | Самочувствие | 8 | Polar subjective |
| notes | Заметка | Техника | TP comments |

ЧСС в блоке не используется — нагрузка ниже кардио-порога.

## Типы тренировок → рекомендуемые блоки FitGO

| Цель | Блоки листа |
|------|-------------|
| Сила | разминка → силовая → заминка |
| Жиросжигание | разминка → круговая или кардио → заминка |
| Смешанная | разминка → сила → кардио/круговая → заминка |
| Восстановление | разминка → лёгкое кардио Z1–Z2 → заминка |

---

## Формулировка для пользователя (анализ)

При запросе «предложи поля» отвечать структурой:

1. **Контекст** — 1–2 предложения, откуда взята логика (Garmin/ACSM/…)
2. **Таблица полей** — название, зачем, пример
3. **Пресеты** — 2–3 готовых набора чипов для тренера
4. **Что не включать** — и почему (лишнее для мобильного)
