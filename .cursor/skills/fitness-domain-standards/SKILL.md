# FitGO — мировые стандарты фитнес-домена

## Главный принцип

При добавлении новых функций в **FitGO** опирайся на **мировой опыт**:

- **TrainingPeaks** — структура тренировок, план/факт, метрики нагрузки
- **Garmin** — зоны пульса, темп, дистанция, интервалы, таймеры
- **Strava** — дистанция, темп/pace, сегменты, сравнение сессий
- **Polar** — зоны Z1–Z5, % от макс. ЧСС, субъективная нагрузка
- **ACSM FITT** — Frequency, Intensity, Time, Type — база для любого кардио/ОФП блока

Не копируй бумажные бланки и «таблицы ради таблиц». Проектируй **под мобильный ввод тренера** и **понятный просмотр клиентом**.

## Когда применять skill

- Новый блок тренировочного листа или поля записи
- Таймеры, интервалы, круговая, кардио, силовая
- Итоги сессии, RPE, ЧСС, зоны, динамика прогресса
- Рекомендации тренеру (подсказки, пресеты полей)
- Любой вопрос «какие поля / как лучше сделать» в контексте FitGO

## Workflow для новой функции

1. **Определи тип нагрузки** (непрерывное кардио, интервалы, сила, круговая, смешанная).
2. **Сверься с FITT** — что тренер реально фиксирует: тип, интенсивность, время, частота.
3. **Посмотри аналоги** — как поле называется и в каком порядке в Garmin/Strava/TrainingPeaks.
4. **Минимум полей по умолчанию** — 3–4 обязательных; остальное включается тренером (чипы/пресеты).
5. **Мобильный UX** — вертикальные карточки, динамические строки (+), без горизонтального скролла.
6. **Двойная метрика интенсивности** — объективная (ЧСС/зона) + субъективная (RPE), где уместно.
7. **Миграция** — старые поля маппить в `normalize*` в `@fitgo/shared-types`, не ломать сохранённые листы.

## ACSM FITT — шпаргалка

| Буква | Смысл | В FitGO |
|-------|--------|---------|
| **F** Frequency | Как часто | Расписание, история сессий |
| **I** Intensity | Насколько тяжело | ЧСС, зона, RPE, вес, темп |
| **T** Time | Сколько длилось | мин/сек, длительность блока |
| **T** Type | Что делали | модальность, упражнение, станция |

## Пресеты полей (уже проверено в FitGO)

### Кардио

| Сценарий | Поля |
|----------|------|
| По умолчанию | тренажёр/вид, время, ЧСС, RPE |
| Дорожка | + наклон, зона |
| Бег/вело/гребля | + дистанция, темп |
| HIIT | + интервалы (протокол), ЧСС, RPE |

Полный список полей и плейсхолдеры — в `packages/shared-types` (`CardioFieldId`, `CARDIO_FIELD_*`).

### Силовая

- вес и повторы **раздельно** (не «кг×повт» в одной ячейке)
- RPE, отдых (сек), темп на подход
- 1 упражнение + 1 подход по умолчанию, **+ подход** / **+ упражнение**

### Круговая

- станция: время работы, отдых, нагрузка, целевая ЧСС, темп (силовые станции)
- сессия: круги, отдых между кругами, журнал RPE/ЧСС по кругам
- чередование: кардио ↔ сила ↔ кор (см. подсказки в `workout-trainer-tips.ts`)

### Биомеханика

| Сценарий | Поля |
|----------|------|
| По умолчанию | зона тела, тип работы, время, объём, RPE |
| С инвентарём | + инвентарь (коврик, эспандер, блок, базовый тренажёр) |
| Односторонние | + сторона |
| Восстановление | + самочувствие (1–10), заметки |

Инвентарь: собственный вес, коврик, эспандер, фитбол, гантели, блок, кроссовер, базовые тренажёры зала. Без специализированной мед. аппаратуры. Низкая интенсивность — RPE 3–5; ЧСС обычно не фиксируют (ACSM corrective / TrainingPeaks Mobility).

### Сессия целиком

- завершение блока → заметка → сохранение → сворачивание → сборка в **итог занятия**
- личные заметки тренера — **только тренер** (`trainerPrivateNotes`, фильтр на API для клиента)

## Зоны и интенсивность

| Зона / % ЧССmax | Назначение |
|-----------------|------------|
| 50–60% / Z1 | разминка, восстановление |
| 60–70% / Z2 | аэробная база |
| 70–85% / Z3–Z4 | порог, рабочие интервалы |
| 85–95% | короткие интервалы, опытные |

RPE (1–10): 6–7 разминка, 7–8 работа, 9–10 почти отказ / отказ.

## Антипаттерны

- Фиксированная сетка 6×5 или 4×5 пустых строк «как на бумаге»
- Одна ячейка «дистанция, наклон» — разделять
- Только ЧСС без RPE (или наоборот) на персональной тренировке
- Горизонтальные таблицы на мобильном без выбора колонок
- Новые поля без нормализации и миграции в `workout-sheet.ts`
