# Hoster proxy for `lk.ffs.by`

Copy **only** these files into the docroot of `lk.ffs.by` (empty site, not ffs.by WordPress):

- `index.php`
- `.htaccess`
- `maintenance.html`

Upstream defaults to Host `lk.ffs.by` on club `:444` → Next client-web `:3002`.

See [docs/DEPLOY_CLIENT_LK.md](../../docs/DEPLOY_CLIENT_LK.md).
